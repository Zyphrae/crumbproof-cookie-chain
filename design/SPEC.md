# Crumbproof implementation specification

Concept: concept.png (1536×1024), generated with the built-in image tool before coding.
Primary surface: working proof creation, verification, and wallet receipt history.
Palette: off-white #f7f7f2, evergreen #123a2b, near-black #0b1914, secondary #53615c, borders #d2d8d2.
Type: Georgia editorial serif for primary/aside headings; system sans for labels and controls; monospace for digests.
Container: 1344px at 1536 viewport (96px side margins), header divider, two-column 66/34 primary area, single white form panel, open numbered right rail. No decorative media.
Corners: 7–10px; no shadows. Icons: 2px document/check line icons.
Allowed create-screen copy is the concept image's exact header, hero, fields, steps, public-data strip and footer text.
Workflow-required extensions in this same style: review modal with exact public data, estimated fee and wallet; sign/status; verification form and matched/unmatched file result; bounded history; setup help; errors and loading states. These are functional states, not additional marketing claims.
Mobile: stack the form and explanatory rail, wrap navigation with full keyboard access, no horizontal overflow. File hashing and financial signing controls must remain distinct.
No invented live stats or example transaction history. A receipt proves a file digest was recorded by a wallet, not authorship, quality, payment or ownership.
